# Portfolio

Personal portfolio site showcasing production-grade AI automation projects.

**Live site:** https://giamarigkos-del.github.io/portfolio/

## About

This site presents three multi-agent AI systems built independently, combining no-code orchestration (n8n, Botpress) with prompt engineering and Python. One of these systems was presented to Delivery Hero senior leadership as a reference model for their company-wide agentic AI initiative.

## Projects Featured

- **Operational CoPilot**: Multi-agent AI platform for partner store management, performance insights, and proactive guidance
- **Catalog Autofill**: AI-powered extraction converting unstructured vendor menus into structured product catalogs, 100% accuracy on a real-world test set
- **Partner Support Agent**: Conversational support agent handling partner queries end-to-end with multi-agent orchestration

## Tech Stack

- HTML, CSS, JavaScript (no frameworks)
- Deployed via GitHub Pages
